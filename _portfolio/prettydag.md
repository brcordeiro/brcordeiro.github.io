prettyDAG is a Python wrapper for styling and visualizing directed acyclic graphs (DAGs) in [doWhy](https://www.pywhy.org/dowhy/), the causal inference library. It provides a cleaner, more expressive API for controlling the appearance of causal graphs without having to fight matplotlib or graphviz defaults directly.
